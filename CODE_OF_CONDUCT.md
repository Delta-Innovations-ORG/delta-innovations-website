# Code of Conduct

Delta Innovations expects respectful, professional, and ethical behavior from all team members, collaborators, clients, and contributors.

## Expected behavior

- Communicate respectfully  
- Protect client confidentiality  
- Avoid harassment and abusive language  
- Keep project discussions professional  
- Test work before delivery  
- Report blockers early  
- Never expose passwords, tokens, or credentials in GitHub or chat  

## Unacceptable behavior

- Harassment or discrimination  
- Abusive language  
- Sharing confidential client information publicly  
- Committing secrets to version control  
- Misleading clients about scope, timeline, or capabilities  
- Careless production deployments without review  

## Enforcement

Violations may result in removal from projects, restricted repository access, or termination of collaboration.

## Reporting

Report concerns privately to **deltainnovations.co@gmail.com**.
