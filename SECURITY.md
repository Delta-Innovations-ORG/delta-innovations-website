# Security Policy

Delta Innovations follows secure development practices for this website and client projects.

## Security principles

- Do not commit secrets or `.env.local`  
- Use environment variables for API keys  
- Use HTTPS in production  
- Apply least-privilege access to dashboards  
- Keep dependencies updated  
- Enable EmailJS **Use Private Key** mode for the contact form  

## Reporting a vulnerability

**Do not** open public GitHub issues for security vulnerabilities.

Report privately to:

- **deltainnovations.co@gmail.com**  
- **insider.daltainnovations@gmail.com**

Include:

- Description of the issue  
- Steps to reproduce  
- Impact assessment  
- Your contact (optional)  

We aim to acknowledge reports within **5 business days**.

## Supported versions

| Version | Supported |
|---------|-----------|
| `main` branch (production deploy) | Yes |
| Older forks or copies | No |

## Out of scope

- Social engineering against individuals  
- Denial-of-service attacks  
- Issues in third-party services (EmailJS, Vercel) — report to those vendors directly  

Thank you for helping keep Delta Innovations and our clients secure.
